# Agent guidance — php-io-extensions/avkit

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the Objective-C, or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1** at AVFoundation, AVFAudio, AVKit, CoreMedia and CoreVideo. One PHP class per native class or CF type, one method per selector, keywords joined in camelCase (`assetReaderWithAsset:error:` → `assetReaderWithAssetError()`). A C function is a global PHP function under its C name (`CMSampleBufferGetImageBuffer()`). Constants keep their SDK names. No defaults, no composites, no convenience the frameworks do not have. Values come from the macOS SDK headers.
3. **Refusals.** The rule, verbatim, as in appkit AGENTS.md item 3:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   avkit keeps no refusal. A kept refusal reads `if (!AVKIT_PROBE_OFF("<id>") && (<check>))`, carries `/* binding:<id> */` on its throw line, has its `sites` entry, and a probe in `tests/Probes`. Probe builds use `AVKIT_CONFIGURE=--enable-avkit-probes ./install-macos.sh`. Never ship a probe build.
4. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the SDK headers of `AVKIT_FRAMEWORKS` in `config.m4`; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` function (`avkit_cmtime_from`, `avkit_cmtimerange_from`, `appkit_nsdictionary`). A `ZEND_FUNCTION` must be written out, not made by a macro: the pre-commit hook matches each one to its stub. `/opt/homebrew/bin/python3 ~/.agent-guards/ext-guard.py tree .` prints `clean` when the tree passes.
5. **On appkit.** avkit's classes are ext-appkit objects: `ZEND_MOD_REQUIRED("appkit")`, compiled against appkit's installed `php_appkit_api.h`, registered with `AVKIT_MAP` (an Objective-C class appkit's boxing finds) or `AVKIT_CF` (a CF type boxed with `appkit_box_cf_as`). `NSURL`, `NSError`, `NSSize`, `NSView` and `CFType` are appkit's. An `NSException` becomes appkit's `AppKitException` (`APPKIT_BEGIN` / `APPKIT_END`). See [`.okf/architecture/appkit.md`](.okf/architecture/appkit.md).
6. **Handles and values.** One PHP object per native object, retained while PHP holds it; private `__construct`, not cloneable, not serializable, `pointer()` / `fromPointer()` from appkit. A `Copy` function or selector's +1 result is released after boxing. `CMTime`, `CMTimeRange`, `CMVideoDimensions` and `AudioStreamBasicDescription` are `final` value classes with public properties named as the C fields, every field a required constructor argument.
7. **Enums** are int-backed PHP enums, cases FULLY UPPERCASE, each value `_Static_assert`-checked against the SDK. No class constants.
8. **Errors.** `NSError**` is a by-reference `?NSError &$error = null` in native position; nil is `null`. A CoreMedia or CoreVideo status is the returned `int`.
9. **The stub is the declaration.** One stub per framework in `stubs/`, registered from the `.m` file of that framework (`AVKit.stub.php` from `src/AVPlayerView.m`: the volume is case-insensitive and `src/avkit.m` is the module). Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, and commit both. Never hand-edit `*_arginfo.h`.
10. **Build.** Install ext-appkit first, then `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts`. Pest at `-d memory_limit=128M` on both. Tests need a temporary `composer install`; remove `vendor/` and `composer.lock` after. Gate a commit on the suite's exit code. The test clip is base64 text (`tests/Fixtures/clip.mp4.b64`): the guard blocks binary writes into the repo.
11. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`. Run `php84 scripts/support.php` after a stub change: it rewrites `SUPPORT.md` and the README's API badge, and `tests/SupportTest.php` fails while either is stale.
12. **Version** is `PHP_AVKIT_VERSION` in `php_avkit.h`: 0.11.2. macOS only.
